# Halloween Office Board

Full-screen Halloween TV board for the 3R Plumbing & Mechanical office.

**Live:** https://ross680.github.io/Halloween-Office-Board/

The page loops `assets/halloween.mp4` with sound: the shop clip, then the “Happy Halloween from 3R Plumbing & Mechanical” outro. Browsers usually block unmuted autoplay, so the first visit shows a large **Tap for sound** button. Click it, tap the screen, or press Enter on the remote once. That choice is remembered and later loads try to start with sound. If the browser blocks audio again, the button comes back until someone taps it.

Leave the live URL open on the office TV. The page asks the browser to keep the screen awake, hides the cursor when it sits still, restarts the video if playback stalls, and reloads itself every six hours.
